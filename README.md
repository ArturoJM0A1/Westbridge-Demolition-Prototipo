# Westbridge Demolition

Sitio web corporativo de Westbridge Demolition, contratista comercial de demolición en el sur de Florida. Construido con React 18, TypeScript y Vite, presenta un diseño premium minimalista con paleta única en ámbar, tipografía editorial Inter e iconografía lucide-react, incluyendo páginas de inicio, servicios, proyectos, seguridad y contacto.
